# Registro de decisiones

Registrar solo decisiones **reales y duraderas**. Marcar si son confirmadas o propuestas. No registrar datos sensibles.

## Plantilla

### AAAA-MM-DD — [Título corto]
- **Estado:** Confirmada / Propuesta / Reemplazada
- **Decisión:** [qué se decidió]
- **Motivo:** [por qué]
- **Impacto:** [pantallas, negocio o arquitectura]
- **Verificación:** [si se implementó/probó o sigue pendiente]
